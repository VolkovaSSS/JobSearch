# **Приложение для получения и анализа вакансий с сайта hh.ru**
## Описание
- получает вакансии с сайта по ключевому слову
- генерирует JSON-файл для анализа этих данных
- вывод в консоль вакансий по заданным условиям
## Структура проекта
- main.py - запускаемый файл
- src/user_menu.py - основной интерфейс 
- src/api_utils.py - получает данные с сайта 
- src/file_utils.py - сохраняет структурированные данные в файл
- src/vacancies.py - класс Вакансия
- src/utils.py - вспомогательные функции
- data - файлы с данными о транзакциях и настройками пользователя
- tests - папка с тестами

## Установка
- Клонируйте репозиторий:
```git clone git@github.com:VolkovaSSS/pythonProject1.git```
- Установите зависимости:
```pip install -r requirements.txt```
## Использование
Для использования нужно запустить файл main.py
например: python main.py
### Зависимости
- Python 3.x
- requests = ">=2.25.1"
- flask = ">=2.0.1"
## Тестирование
При тестировании использовался фреймворк pytest

Для запуска тестов выполните команду:
```sh
pytest --cov=src --cov-report=html
```
